# Roadmap

The public preview includes a process workbook and manual committee collaboration, with local persistence, independent reviews, readiness, examples and document packages. Future work should be driven by church and pastoral feedback.

- Better document output: DOCX, dedicated PDF composition, Google Docs export.
- Optional encrypted attachments and refined local candidate-record recovery, informed by the committee battle test; never a candidate marketplace or automatic ranking service.
- Optional authenticated Committee Workspace, preserving the local/manual bridge. See [phased collaboration roadmap](roadmap-collaboration.md): A manual bridge (implemented), B private shared workspace, C demonstrated collaboration needs, D optional private assistance.
- Optional local document parsing and later AI-assisted extraction from constitutions, bylaws and doctrinal statements. Every suggested rule requires human confirmation; manual input remains authoritative.
- More explicitly labeled fellowship and polity presets with declared theological assumptions; no claim that differing models are theologically equivalent.
- Translation/i18n, more screen-reader testing, accessibility improvements, and additional artifact templates.
- Search-cycle archive and reviewed, sanitized reusable church configuration. The schema already separates template suggestions and provides a conservative extraction boundary, but arbitrary free text still needs human review.
- Incremental TypeScript migration of the existing UI modules as contributor needs justify it.

Accounts, cloud synchronization, native apps, complex permissions, denominational administration, AI candidate scoring and automated pastoral recommendations are intentional MVP non-goals.

Before adding a backend, run the [committee battle test](collaboration-battle-test.md). Evaluate packet handoff, independent review, minority concerns, deterministic question grouping, assignments and decision history. Notifications, discussion threads, attachments, server-enforced sealing and retention tools remain deferred until demonstrated useful.
